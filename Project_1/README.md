# Project 01 – Shark Tank India Startup Investment Analysis

### 📅 Date: December 09, 2025  
### 🧑‍💻 Intern: Ammar Hasware

---

## 🎯 Objective
Analyze startup investment trends using Shark Tank India datasets

---

## 🔍 Project Overview

- Which brands secured deals
- Which sharks invested the most
- Investment trends across episodes
- Equity vs. debt patterns
- Category-wise performance of pitches
- Insights into pitchers, ideas, and funding amounts

--

## 🔧 Data Cleaning & Preparation Steps

- Removed extra spaces from columns
- Converted the Datatype of a column properly
- Created a separate Investors table for better slicer performance
- Added DAX measures like:
    - Total Investment
    - Total Deals
    - Average Equity
    - Investor-wise Investment

- Generated KPIs and slicers for deep analysis.
--

## 🧠 Key Learnings
- Designing interactive dashboards with drill-through
- Creating a clean data model for Power BI
- Handling Yes/No categorical investor fields
- Building useful DAX measures
- Converting business problems into analytical insights

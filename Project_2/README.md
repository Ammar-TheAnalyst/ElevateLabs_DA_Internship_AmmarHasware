# Project 02 – YouTube Trending Video Analytics

### 📅 Date: December 13, 2025  
### 🧑‍💻 Intern: Ammar Hasware

---

## 🎯 Objective
Uncover patterns in trending videos by analyzing YouTube datasets across region.

---

## 🔍 Steps Involved
1. **Data Extraction and Cleaning**  
   - Loaded YouTube trending data and checked schema, data types, and missing values.  
   - Standardized date fields and converted Boolean columns for database compatibility.

2. **Sentiment Analysis**  
   - Applied VADER sentiment analysis to classify video titles and tags as positive, neutral, or negative.  

3. **SQL Analysis**  
   - Aggregated data to calculate metrics such as average views by content category and identify high-performing genres.

4. **Data Visualization**  
   - Designed Tableau dashboards to compare genres and sentiments, analyze engagement across countries, and observe time-series trends.

---

## 🧠 Key Findings
- Certain content categories consistently achieve higher average views, indicating strong audience preferences.  
- Neutral and positive sentiments dominate trending content.  
- Engagement varies significantly across regions.  
- Time-series analysis shows growth patterns in average views over time.
